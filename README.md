# 📦 Manajemen Barang

Sistem sederhana untuk mengelola data barang berbasis PHP & MySQL.

---

## 🚀 Fitur

- Tambah data barang
- Edit data barang
- Hapus data barang
- Tampilan responsive dengan Bootstrap
- Menggunakan Bootstrap Icons (offline)
- Database contoh tersedia (`example_database.sql`)

---

## 🛠 Teknologi yang Digunakan

- PHP
- MySQL
- Bootstrap (local file)
- Bootstrap Icons (local file)
- JavaScript

---

## 📂 Struktur Project

```
Manajemen-barang/
│
├── index.php
├── function.php
├── example_database.sql
├── bootstrap.min.css
├── bootstrap.bundle.min.js
├── script.js
├── style.css
└── bootstrap-icons-1.11.3/
```

---

## ⚙️ Cara Menjalankan

1. Clone repository:
   ```
   git clone https://github.com/unknown534/Manajemen-barang.git
   ```

2. Import database:
   - Buka phpMyAdmin
   - Buat database baru
   - Import file `example_database.sql`

3. Jalankan di localhost:
   - Letakkan folder di `htdocs` (XAMPP) atau `www` (Laragon)
   - Akses melalui browser:
     ```
     http://localhost/Manajemen-barang
     ```
